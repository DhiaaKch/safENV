FEATURES ENGINEERING BLUEPRINT - CERT r4.2 + REAL-WORLD INSIDER THREAT
Version: 1.0
Window anchor: user_id x 1h (UTC)

OBJECTIVE
Build a robust, explainable and production-ready feature set for:
1) Binary detection: malicious vs normal
2) Scenario classification: CERT scenarios 1..5
3) Generalization to real-world insider patterns

DATA REALITY (IMPORTANT)
- Available sources: logon, device, file, http, email, ldap.
- Some "ideal" features (bytes upload/download, process execution, failed logins, geolocation) are not present directly.
- Keep two layers:
  A) Core features (immediately computable from current data)
  B) Extension features (add when extra telemetry exists)

============================================================
G. QUALITY RULES FOR ROBUSTNESS
============================================================

- No target leakage: never use future windows in current-row features.
- All rolling stats use past-only windows.
- Robust scaling preferred over standard scaling for heavy-tailed counts.
- Stratify evaluation by user and by scenario.
- Report both:
  - binary metrics (AUC-PR, F1@k, recall@top-k)
  - multiclass scenario metrics (macro-F1 + per-scenario recall)
